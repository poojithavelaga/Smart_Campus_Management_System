# Smart Campus Management System

## Overview
Smart Campus Management System is a Java-based desktop application developed using Java , JDBC, and MySQL. It helps manage students, faculty, attendance, events, and complaints through a centralized platform.

## Features
- Student Management
- Faculty Management
- Attendance Management
- Event Management
- Complaint Management
- Secure Login System

## Technologies Used
- Java
- JDBC
- MySQL

## Project Structure
- StudentManagement.java
- FacultyManagement.java
- AttendanceManagement.java
- EventManagement.java
- ComplaintManagement.java
- Login.java
- MainMenu.java
- DBConnection.java

## Database
MySQL is used as the backend database.

## Future Enhancements
- Role-based access control
- Report generation
- Email notifications
- Cloud database integration
